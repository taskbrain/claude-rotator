## T1 案A の短期再現

1. 試験用レーンフォルダ `L1` を作り、口座14（fde@）で正規 `/login`（坂根さん）。セッションを1つ起動したままにする。
2. 口座15（develop@）は別フォルダ `S15` で正規 `/login`（坂根さん）し、閉じる。これを「移す元」にする。
3. ヘルパー（実装は試験用。値を表示しない）で、`S15` の最新の認証情報と `oauthAccount` を `L1` に**移す**（移した後は `S15` を使わない）。`L1` にあった14の最新は保護した保管場所へ移す。
4. 切り替えのたびに 0/3/10/30/60 秒で `/status`・`/usage` を見て、短い質問をする。
5. 14 と 15 の間で5往復。最後に一度だけ、承認された無害な文面で `/feedback` を送る。
- 合格: 再起動なしで、60秒以内に表示と `/usage` が一致し、短い質問が通る。戻しも同じ。`/feedback` が送信成功と受付 ID を返す。確認画面が出ない。

## T2 案A の長期維持

2. 最低72時間。動いている口座と休んでいる口座の両方で、Claude Code による自然な更新（項目の mdat が進む）を各2回以上見る。
